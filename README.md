# chatGPT Game Project

## Guess the Number Game

This repository contains a simple command-line game in Python.
It now also includes a minimal 3D demo using `pyglet`.

### Running the Game

```
python guess_game.py
```

The game will generate a secret number between 1 and 100. Try to guess it! After each guess you'll be told if the secret number is higher or lower.

## Simple 3D Demo

This project also contains a minimal 3D game that displays a rotating cube and plays a sound when you press the `SPACE` key.

### Requirements

* Python 3
* `pyglet` library

Install the dependency with:

```
pip install pyglet
```

### Running the 3D Demo

```
python simple_3d_game.py
```

You should see a window with a spinning cube. Press `SPACE` to hear a sound.
